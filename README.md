# منصة تمكين الإعلام القانوني ومراجعة المحتوى للمحامين

منصة عربية RTL مبنية بـ Next.js لدعم مراجعة المحتوى الإعلامي للمحامين، وقياس جودة اللغة والصياغة، وملاحظات الامتثال، ومؤشرات المخاطر، وفرص التحسين، وجاهزية النشر.

## النشر على Vercel

ابدأ من:

[DEPLOYMENT_CHECKLIST.md](./DEPLOYMENT_CHECKLIST.md)

## إعداد العرض الأول

النسخة الأولى على Vercel لا تحتاج إلى قاعدة بيانات.

المنصة تستخدم بيانات عرض أولية وخدمات محاكاة، لذلك لا تحتاج إلى:

- PostgreSQL
- SQLite على Vercel
- Docker
- Prisma migrations
- كلمات مرور قاعدة بيانات

## متغيرات Vercel المطلوبة

```env
AI_PROVIDER=mock
NEXT_PUBLIC_DEMO_MODE=true
```

لا تضف `DATABASE_URL` للعرض الأول على Vercel.

## النفاذ الوطني الموحد

يبقى حساب العرض «ياسمين» هو طريقة الدخول الفعالة حاليًا. تكامل
النفاذ الوطني جاهز تقنيًا لكنه معطل إلى حين استكمال الموافقة الرسمية
واستلام بيانات الاعتماد الحقيقية. لا تستخدم المنصة بيانات أو استجابات
مصادقة وهمية.

راجع [توثيق تفعيل النفاذ الوطني](./docs/NAFATH_ACTIVATION.md) لمعرفة متغيرات
البيئة والاعتمادات الرسمية المطلوبة مستقبلًا.

## مستخدمو العرض الأولي

كلمة المرور لكل المستخدمين:

```text
Demo@12345
```

- lawyer@example.com
- supervisor@example.com
- admin@example.com

## الضوابط المهنية

المنصة لا تنشئ ترتيبا للمحامين، ولا درجات سمعة، ولا تقييما عاما فرديا. مؤشرات المشرفين مجمعة فقط، ولا توجد وظائف لإدارة القضايا أو خدمات الترخيص.

## قاعدة بيانات حقيقية لاحقا

بعد جاهزية العرض الأولي للبيانات المستمرة، استخدم PostgreSQL للإنتاج من خلال Vercel Postgres أو Neon أو Supabase.
