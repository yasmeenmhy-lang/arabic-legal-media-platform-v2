# تفعيل النفاذ الوطني الموحد

النفاذ الوطني الموحد اعتماد إنتاجي خارجي. يظل معطلًا، ويستمر حساب العرض
«ياسمين» كطريقة الدخول الفعالة، إلى أن تُستكمل الموافقة الرسمية
وتُسلّم بيانات الربط الحقيقية.

## السلوك الافتراضي الآمن

```env
NEXT_PUBLIC_DEMO_MODE=true
NAFATH_ENABLED=false
```

- لا تُرسل طلبات إلى مزود الهوية.
- لا تُستخدم بيانات اعتماد أو استجابات وهمية.
- يظهر الخيار بالنص: «قيد التفعيل بعد استكمال الربط الرسمي».
- يعمل العرض التجريبي وبقية المنصة بصورة طبيعية.

## المتطلبات الرسمية قبل التفعيل

يلزم استلام واعتماد ما يأتي من الجهة الرسمية المسؤولة عن التكامل:

- موافقة الربط الإنتاجي.
- معرّف العميل الرسمي.
- سر العميل الرسمي، ويُحفظ كمتغير بيئة سري.
- عنوان التفويض المعتمد.
- عنوان تبادل رمز التفويض بالتوكن.
- عنوان خدمة بيانات المستخدم.
- عنوان إعادة التوجيه المسجل رسميًا.
- النطاقات والصلاحيات المعتمدة للحساب.
- آلية موثقة لربط الهوية بالأدوار داخل المنصة.

## متغيرات البيئة المطلوبة

```env
NAFATH_ENABLED=true
NAFATH_AUTHORIZATION_URL=https://official-provider.example/authorize
NAFATH_CLIENT_ID=official-client-id
NAFATH_CLIENT_SECRET=official-client-secret
NAFATH_REDIRECT_URI=https://platform.example/api/auth/nafath/callback
NAFATH_TOKEN_URL=https://official-provider.example/token
NAFATH_USERINFO_URL=https://official-provider.example/userinfo
NEXTAUTH_SECRET=long-random-production-secret
```

القيم أعلاه أمثلة لأسماء الحقول فقط وليست بيانات اعتماد أو عناوين إنتاجية.
لا يجوز ضبط `NAFATH_ENABLED=true` قبل اكتمال جميع القيم الرسمية واختبارها في
البيئة المعتمدة. إذا كان أي متغير مفقودًا، يبقى التكامل معطلًا تلقائيًا.
